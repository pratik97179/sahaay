# Sahaay — Ideas

A scratch list for thoughts about the app, or things around it. Nothing here is a requirement. The PRD (`docs/sahaay_prd.md`) stays the source of truth until an idea is written into it on purpose.

## How to add one

Add a dated bullet under **Inbox**. One line is enough. Add a note only if the thought needs it.

```
- YYYY-MM-DD — the idea
```
