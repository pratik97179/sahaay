# Sahaay — Ideas

A scratch list for thoughts about the app, or things around it. Nothing here is a requirement until it is written into the plan or the design docs on purpose.

## How to add one

Add a dated bullet under **Inbox**. One line is enough. Add a note only if the thought needs it.

```
- YYYY-MM-DD — the idea
```
